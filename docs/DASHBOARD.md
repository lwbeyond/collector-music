# 本地音乐看板

用于展示本机采集成果的只读网页。设计原则是“减少多余标签与说明，让布局表达关系”：深色、香槟金与衬线标题，以留白、分栏和细线替代玻璃、渐变、高光及嵌套卡片。后续改动遵循 [看板设计规范](DESIGN.md)。

## 打开

双击项目根目录 `04-打开音乐看板.cmd`，或控制台选 11。程序启动本机后台服务并打开浏览器；重复启动会复用同一资料库的服务。默认地址 <http://127.0.0.1:8767>，没有发布到互联网或局域网。

```powershell
# 前台运行，关闭命令行即可停止
.\.venv\Scripts\python.exe -m collector_music dashboard
# 后台运行并打开页面
.\.venv\Scripts\python.exe -m collector_music dashboard --background
# 指定其他端口或独立资料库
.\.venv\Scripts\python.exe -m collector_music --home "自己的资料目录" dashboard --port 8768
```

若端口已有其他项目或其他资料库的服务，启动器拒绝复用，不会结束该进程。后台输出在 `.local/dashboard.log`；Windows 重启后需重新打开入口，未注册开机常驻任务。

## 页面内容

- 概览：设备 scrobble 与网易云近期观测分别统计；红心与歌单使用各账号最近一次成功的范围快照。统计卡可直接进入对应来源或收藏，自动清除冲突的搜索/时间/类型筛选；首屏提供查记录和红心入口，最近设备记录以曲目、艺人和时间直接展示。
- 导航：顶部导航固定并标记当前区块，手机同样可直接切换位置；“如何更新”在顶部提供接收、采集与发布说明。
- 数据指标与听歌图谱：四个视图统一使用完整已发布观测，独立选择网易云近期/设备来源及近 7/30/90/365 天、全部时间或自定义起止日期。自定义范围包含首尾两日，以发布时的分析时区为准。
  - 歌曲筛选：曲风、语种、推荐标签取网易云原文，三个条件及歌名/艺人/专辑/ID 搜索取交集；下拉数量为全库歌曲数。歌曲清单每页 8 首，包括只有红心或榜单、没有本期观测的歌曲，后者显示“未记录”。清单、四个图表视图、艺人明细、前期对比和导出使用同一筛选。刷新保留选择；空结果、请求失败不保留旧图表。
  - 走势：按日计数，长区间自动汇总为最多 58 个柱。悬停、聚焦或点击查看条数；空心标记表示没有记录、覆盖未知。支持导出当前范围内有记录日期的 UTF-8 BOM CSV，附来源、时区、范围、覆盖状态和发布版本，缺失日期不补成零播放。
  - 24 时分布：小时柱图及星期 × 小时热力图；可点击或用方向键查看时段条数。按当地时区归属日期，夏令时回拨的同一小时正常累计两次观测。
  - 艺人与曲目：艺人/组合标签 Top 10 和曲目 Top 10，显示次数与占全部观测的比例。艺人不拆分；点击标签查询同一来源和范围内的曲目明细，包含历史列表未载入的旧记录。
  - 数据指标：有记录日均、不同曲目占比、艺人标签数、单日峰值、有记录日期数、不同曲目数、最长连续记录日数、凌晨观测占比，以及按需展开的记录摘要和计算说明。无数据时不生成偏好结论。
  - 对比：非“全部时间”范围与紧邻之前的等长自然日对比观测数；前期为零时不计算变化率，明确采集覆盖变化会影响结果。
- 下拉组件：保留深色下拉菜单，触发按钮具有字段名称和所选值；支持方向键、Home/End、Enter、Escape，Tab 离开时收起。隐藏的原生 select 不进入键盘焦点序列。
- 网易云报告：按实际返回月份选择完整月报或实时快照，显示有收听的日期、热门歌曲/艺人及曲风、语种、年代。刷新保留所选月份和报告类型，即使采集产生新的快照 ID；曲风偏好独立显示采集时间，不冒充所选月报的分类。
- 听歌记录：搜索歌名、艺人或专辑；按来源、全部/近 7/30/90 天筛选，时间范围含今日并使用数据的当地时区；按最新/最早排列，每页 10/25/50 条，支持页码跳转和重置。相对日期范围排除无效时间和未来记录；全部时间保留原始记录，无效时间排在末尾。喜欢/取消喜欢动作明确标记，不计入听歌概览。手机用分行列表展示曲目、艺人、专辑、时间和来源。

口径：历史列表默认只看网易云近期观测，“全部来源（核对）”保留双来源证据，不暗示这是去重后的播放流水。疑似双源重合显示时间差；存在多个候选时明确标注，不删除或折叠事实。候选条件与局限见 [数据契约](DATA_CONTRACT.md)。分析只纳入 Pano scrobble 和网易云 recent_observation，排除喜欢/取消喜欢动作；时间缺失、无效或当地日期晚于今天的观测不进入指标。曲目按来源 recording_key 去重，同名不同版本不混为一首。曲目名称与艺人标签使用该曲目标识在完整发布中的最新元数据。“不同曲目占比”和“艺人/组合标签数”不被解释为探索度或个人艺人数。
- 榜单：切换周榜/总榜，显示上游报告次数；更多条目可展开，不跨采集日相加。
- 收藏：红心详情和歌单清单均可搜索、分页、按页码跳转并清空筛选，显示总数和当前页；歌单可筛选“我创建的 / 我收藏的”，概览明确各自数量。红心按 ID 关联采集到的名称、艺人、专辑和曲长；存在缺失时明确显示仅有 ID 的数量，未取得详情的 ID 仍保留。曲长不是实际聆听用时。
- 跳转：听歌记录、榜单、红心和最新记录中的曲名可打开网易云。带歌曲 ID 的使用歌曲页，无 ID 的设备记录使用歌名与艺人搜索；不伪造精确匹配。歌单名称打开对应网易云歌单。外链新窗口打开且不发送本页 referrer。
- 来源：设备最近接收时间、已收到记录数、账号各范围的采集状态；不是实时 USB 连接状态或后台在线证明。

刷新展示只重新读取已发布资料，保留当前搜索、筛选和页码（超出新数据页数时调整到末页），按钮直接提示读取结果。手机日志接收用 `03-接收手机日志.cmd`，网易云采集用 `02-采集账号快照.cmd`，完成后返回页面刷新。首次未发布或资料校验失败均有独立状态；读取失败保留当前屏幕并提示错误。

最近一次采集失败时，收藏/榜单保留之前的成功快照并标记过期；成功返回空列表才显示 0。实际听歌时长仍未知，不显示从曲长拼凑的听歌分钟数。

歌曲目录按网易云歌曲 ID 唯一化，同 ID 跨近期、历次红心和榜单合并，同名不同 ID 各自保留；多曲风或多标签不会重复计算观测。标签采用当前发布中的最新成功结果，并用于整个所选历史区间，不代表播放当时的标签。缺失字段留空，待补采、平台全空、采集失败、保留旧标签分别标记。标签筛选仅关联确切网易云 ID；当前无该 ID 的 Pano 记录不会按曲名猜配，设备来源下会提示未关联数量。未筛选时设备统计照常显示。

平台报告同样区分成功、空报告、采集失败与保留旧快照；成功空报告不会复活更早的内容，空报告之后又采集失败也继续显示为空。报告时间范围沿用平台返回，完整月报和当前月实时进度不会混用。时长原值的单位尚未核实时，页面仅提示待核实，不将其标为分钟；已验证的 `duration_minutes` 才能进入时长指标和每日图表。未知日期不补零。曲风、语种、年代占比保留平台口径，歌曲分类不用于推断个人情绪。

## 实现与边界

Python 标准库 HTTP 服务 + 本地 HTML/CSS/JavaScript；复用 DuckDB 和版本化 Parquet。启动和读取不修改活动 SQLite，不接受任意 SQL 或采集写入请求。HTML、脚本、样式打包在 `collector_music/web`。

首次加载以及发布指针变化时校验 manifest、文件哈希、字段和行数，再固定该版本生成展示；点击刷新会强制重新校验。相同版本普通请求复用内存结果。仅绑定 127.0.0.1，校验 Host/Origin，静态文件按白名单提供，不能借路径读取 `.local`、raw 或数据库。无外部字体、图像、分析脚本或 API 请求；页面所有来源文本以文本节点显示。

当前听歌记录列表最多载入最近 5,000 条，超过时在搜索旁及空结果提示中明确范围；历史列表搜索和排序限于已载入片段。红心和歌单加载最近成功快照的完整清单，在浏览器按每页 10 项展示。所有分析视图、艺人明细和导出均不受历史列表上限影响。分析索引按来源、当地日期、小时和曲目标识压缩计数，适合个人规模，未承诺无限内存容量。

`GET /api/dashboard` 的 `platform_reports` 只含平台报告的规范化展示字段及采集时间，不输出账号标识、朋友资料或原始响应。报告与本地播放观测独立发布、独立展示；只在发布指针更新后读入新报告。看板兼容 1.0.0、1.1.0 和含歌曲标签数据集的 1.2.0 发布，缺少报告数据集的旧发布显示“尚未采集平台报告”。

`song_catalog` 提供全库标签选项、歌曲数和采集状态数；`GET /api/analytics` 可加 `genre`、`language`、`tag`（精确平台原文）及 `q`（不区分大小写的子串搜索），每项最多 200 字。响应带符合条件的完整歌曲清单、逐曲本期观测数和已关联歌曲数，均来自同一固定发布。查询和统计不受历史列表 5,000 条上限影响。CSV 额外保留四个筛选条件；页面不直接访问平台接口。

`GET /api/analytics?generation=...&source=pano&period=30` 返回日统计、24 小时分布、7×24 热力图、前十艺人/曲目、指标及对比结果。`period=custom` 需要 `start/end=YYYY-MM-DD`；`artist` 为精确标签筛选。参数严格校验，不接受 SQL。发布版本不一致返回 409，要求刷新展示；日期和参数无效返回 400；读取或完整性检查失败返回 503。分析和看板共用校验过的固定发布，刷新时重建索引；跨午夜时相对日期范围自动使用当天日期。前端取消过期请求，加载或失败时清空不匹配的图表，避免旧结果冒充新筛选结果。

扩展组件可读取 `window.CollectorMusicAnalytics.getAnalysisData()` 的当前完整统计结果，加载中或失败时为 null。兼容保留的 `getAnalysisRecords()` 只返回当前范围内已载入的历史片段，不应用于全量指标；`getState().data.records` 仍是原始来源列表。扩展插槽默认隐藏，注册组件时才显示。

## 验收

看板按桌面场景设计。浏览器测试使用 Playwright 1.63.0 和本机 Microsoft Edge；测试截图写入 Git 忽略的 `.local/dashboard-qa/`。

```powershell
.\.venv\Scripts\python.exe -m collector_music dashboard --background --no-open
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
npm.cmd run test:ui
# 自建临时资料库，无需个人数据或预先启动服务器
npm.cmd run test:analytics
# 自建小型临时资料库，覆盖平台报告展示与日期/失败边界
node tests/reports.browser.mjs
```

`test:ui` 需要非空的已发布记录和本机 Edge；它只读取资料，HTML 注入/空状态通过请求拦截模拟。`test:analytics` 自建包含 5,006 条设备播放的临时发布并启动随机端口服务，结束后清理临时资料；验证旧记录明细、自定义日期、CSV、快速切换请求、失败重试、键盘操作、注入防护、空状态及桌面/窄屏四个视图。截图保存在 `.local/dashboard-qa/`，不会提交到 Git。

`reports.browser.mjs` 使用合成报告验证完整月报/实时快照切换、失败保留旧值、成功空报告、未知单位不换算、来源文本注入和键盘操作。截图中的数值为测试夹具。
